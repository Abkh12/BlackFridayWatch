# Black Friday Watch — نسخه اندروید مستقل

این پروژه برای اجرای مستقیم روی گوشی طراحی شده است: دیتابیس SQLite داخل خود گوشی است و هیچ کامپیوتر یا سرور شخصی لازم ندارد. جست‌وجو فقط با فشردن دکمه انجام می‌شود.

## امکانات پیاده‌سازی‌شده
- رابط فارسی و راست‌چین
- جست‌وجو با نام کالا یا لینک محصول
- تلاش برای دریافت داده از دیجی‌کالا، ترب، ایمالز و تکنولایف
- نمایش نتایج و کمترین قیمتِ دریافت‌شده
- ذخیره محلی محصول و هر قیمت دریافت‌شده در SQLite
- مشاهده تاریخچه قیمت و بازکردن صفحه فروشنده
- حذف محصول و سوابق آن
- ساخت APK با GitHub Actions

## ساخت APK بدون کامپیوتر شخصی
1. یک Repository در GitHub بساز.
2. تمام محتویات این پوشه را در ریشه Repository بارگذاری کن.
3. وارد تب Actions شو و گردش‌کار `Build Android APK` را اجرا کن.
4. پس از موفقیت، از بخش Artifacts فایل `BlackFridayWatch-release-apk` را دریافت کن.

Workflow خودش پروژه پلتفرم Android را تولید می‌کند؛ لازم نیست فایل‌های Gradle را دستی بسازی.

## وضعیت اتصال سایت‌ها — مهم و شفاف
- دیجی‌کالا: جست‌وجو از مسیر JSON شناخته‌شده `api.digikala.com/v1/search/` پیاده‌سازی شده است. ساختار پاسخ ممکن است تغییر کند.
- ترب، ایمالز و تکنولایف: جست‌وجوی وب‌سایت و استخراج داده‌های ساختاریافته (JSON-LD و متادیتای محصول) پیاده‌سازی شده است. این روش به HTML قابل‌دسترسی و وجود داده ساختاریافته وابسته است؛ صفحات JavaScript-heavy، ضدربات، CAPTCHA یا تغییر ساختار ممکن است نتیجه ندهند.
- برنامه عمداً قیمت ساختگی تولید نمی‌کند. اگر منبعی نتیجه ندهد، دلیل یا وضعیت عدم دریافت را نشان می‌دهد.
- برای لینک مستقیم، لینک باید متعلق به یکی از چهار دامنه پشتیبانی‌شده باشد. اگر سایت صفحه را با داده قابل استخراج ارائه کند، تلاش می‌شود قیمت و عنوان خوانده شود.
- این نسخه هنوز از API رسمی/تضمین‌شده تجاری این چهار شرکت استفاده نمی‌کند و دریافت قیمت زنده از هر چهار سایت در همه شرایط تضمین‌شده نیست.

## واحد پول و تطبیق کالا
مقادیر استخراج‌شده به‌عنوان تومان نمایش داده می‌شوند. تبدیل فیلد قیمت API دیجی‌کالا در کد بر اساس قرارداد رایج فیلدهای ریالی انجام می‌شود؛ باید با نمونه‌های زنده هر نسخه API بازبینی شود. قیمت‌ها را قبل از خرید در سایت اصلی بررسی کن. محصولات با مدل، حافظه، رنگ، گارانتی یا موجودی متفاوت ممکن است کالای یکسانی نباشند؛ برنامه فعلاً تطبیق هوشمند قطعی بین مدل‌های متفاوت انجام نمی‌دهد.

## توسعه محلی (اختیاری)
با Flutter 3.24 یا جدیدتر:
```bash
flutter create --platforms=android --org com.blackfridaywatch .
flutter pub get
flutter analyze
flutter build apk --release
```

پروژه برای Android و ذخیره‌سازی محلی طراحی شده است. فایل APK در GitHub Actions تولید می‌شود؛ در این محیط فعلی امکان اجرای Flutter/Android SDK و تأیید نصب APK وجود ندارد.
